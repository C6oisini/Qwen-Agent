# 头条项目级别决策修改助手

适用场景：按项目ID查看表现并精确调整日预算、出价或 ROI 目标。

## 快速步骤
1) **查询**：用 `query_ad_data` 按项目ID分组，拉取决策指标。询问用户投手，账户，游戏等信息。注意：用户明确了项目id则直接进入修改阶段

2) **筛选**：根据阈值或用户要求挑选需调整的项目（例：ROI>0.1 且 消耗>5000 提高预算；ROI<0.01 且 消耗>3000 降低预算/出价）。
3) **准备更新**：为每个项目形成 item，字段包含：
   - `account_id`（或 `cid`）
   - `adgroup_id`（项目ID）
   - 至少一个可调参数：`daily_budget` / `roi_goal` / `time_range`
   - 可选：`end_date`
4) **批量更新**：调用 `update_tt_projects`，items ≤ 10。

**示例**：
```json
{
  "method": "tools/call",
  "params": {
    "name": "update_tt_projects",
    "arguments": {
      "items": [
        {
          "cid": "",
          "account_id": "1827167219715081",
          "adgroup_id": "7589919699343179818",
          "daily_budget": 5000,
          "weekly_schedule": {
            "1":{
              "start_time": "00:00",
              "end_time": "00:30"
            }
          }
        }
      ]
    }
  }
}
```
5) **确认**：返回调整明细，提示在头条后台确认任务状态与消耗节奏。

## 输出 / 汇报格式（示例）
- 表头：项目ID | 项目名称 | 消耗 | 累计ROI | 首日ROI | 转化数 | 转化成本 | 日预算(前→后) 
- 文字总结模板：
  - 调整项目数：N；预算总变动：+X/-Y 元/天
  - 主要动作：上调/下调预算、设定ROI目标、限时投放
  - 后续动作：观察1-2天，如 ROI 低于阈值再收紧；如高于阈值且消耗稳定可继续加量

## 执行前检查（D专用）
- 时间范围与分组：是否设置 `start_time` / `end_time`，`group_key` = 项目ID
- 指标是否包含：项目ID、消耗、ROI、转化成本等决策字段
- 调整条件是否明确：ROI / 消耗 / 成本阈值及目标预算/ROI
- 更新参数完整性：`adgroup_id`、`account_id`/`cid`、要修改的字段、日期格式正确、预算单位为元
- 批量限制：`items` 数量 ≤ 10

## 典型策略模版
- **加预算**：ROI > 10% 且 消耗 > 5000 → `daily_budget` 上调 30%-100%
- **降预算/出价**：ROI < 1% 且 消耗 > 3000 → 降低 `daily_budget`
- **调 ROI 目标**：表现稳定但需控风险 → 设置或下调 `roi_goal`
- **限时投放**：高峰投放 → 设置 `time_range` 08:00-23:00
